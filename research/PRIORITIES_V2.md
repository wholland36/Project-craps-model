# NCAAF priorities v2 — additive research only

This extension does not replace the official November 3 release or the frozen injury-shock candidate. New parameter fits and independent production evidence remain outstanding. Use `candidate-frozen.json` for the existing prospective injury experiment; these v2 helpers do not alter it.

Implemented components:

- `availability_v2`: scoped administrative status, ID/role evidence contracts, user replacement prior, separate simultaneous-loss depletion scenario, unknown coverage and baseline-relative injury-burden state. Caller attestation is not independent authentication.
- `probability_v2`: residual-center bookkeeping; shared weighted integer score support; proper scores and same-book/event weighting; block sensitivity and a frozen-policy return auditor. Calibration-only candidate weights have not been fitted.
- `context_v2`: measured context, schema preflight and optional train-only ridge opponent-adjusted regulation efficiency. It requires real complete regulation possession counts; no full-score substitution.
- `collect_game_inputs_v2`: hash-verified cached/free public summary collection with honest clocks and private raw storage. Observed drives are not automatically complete possessions. Historical captures remain retrospective.
- `validation_v2`: source capture, immutable research records, power-planning utility and explicit unmet readiness gates. It never automatically approves a model.
- `priority_workflow`: retains all games and exports a feature-level readiness inventory.

```sh
../validation-venv/bin/python -m research.priority_workflow --games ../../outputs/injury-shock-20261105/all-627-games.json --output /absolute/new/research-readiness.json

```
